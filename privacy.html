개인정보 처리방침

시행일: 2026년 6월 27일

LoveBridge(이하 "회사")는 커플 캘린더(이하 "앱") 이용자의 개인정보를 중요시하며, 관련 법령을 준수합니다.

1. 수집하는 개인정보

앱은 서비스 제공을 위해 다음 정보를 수집할 수 있습니다:

  • Apple ID 또는 Google 계정 기반 인증 정보 (고유 식별자, 이메일 등 로그인에 필요한 정보)
  • 일정 및 기념일 데이터 (사용자가 직접 입력하거나 연동을 통해 가져온 정보)
  • 커플 연결을 위한 페어링 정보
  • 푸시 알림을 위한 기기 토큰
  • Google Calendar 연동을 사용자가 선택한 경우, 일정 조회·생성·수정·동기화에 필요한 Google Calendar 데이터

2. 개인정보의 이용 목적

  • 커플 간 일정 동기화 서비스 제공
  • 사용자가 선택한 외부 캘린더 연동 및 일정 관리 기능 제공
  • 푸시 알림 발송
  • 서비스 개선, 오류 수정, 보안 유지

3. Google Calendar 데이터 사용

앱은 사용자가 명시적으로 Google Calendar 연동을 선택한 경우에만 Google Calendar 데이터에 접근합니다. 해당 데이터는 사용자가 요청한 캘린더 기능, 예를 들어 일정 표시, 일정 생성, 일정 수정, 일정 동기화를 제공하기 위한 목적으로만 사용됩니다.

앱은 Google Calendar 데이터를 광고 목적으로 사용하지 않으며, 제3자에게 판매하지 않고, 범용 인공지능 또는 머신러닝 모델 학습에 사용하지 않습니다. Google Calendar 데이터에 대한 사람의 접근은 사용자 지원, 보안, 법적 의무 이행 등 필요한 경우로 제한됩니다.

앱의 Google API 정보 사용 및 이전은 Google API Services User Data Policy 및 Limited Use 요구사항을 준수합니다.

4. 개인정보의 보관 및 파기

회원 탈퇴 또는 서비스 종료 시 관련 데이터를 지체 없이 파기합니다. 데이터는 Firebase(Google Cloud) 서버에 암호화되어 저장됩니다. 단, 법령 준수, 보안, 분쟁 해결을 위해 필요한 최소한의 정보는 관련 법령과 내부 정책에 따라 일정 기간 보관될 수 있습니다.

5. 제3자 제공 및 처리 위탁

앱은 사용자의 개인정보를 제3자에게 판매하지 않습니다. 단, 서비스 운영에 필요한 다음 서비스를 이용할 수 있습니다:

  • Firebase (Google) - 인증, 데이터 저장, 푸시 알림, 서비스 운영
  • Google Calendar API - 사용자가 선택한 캘린더 연동 기능 제공
  • RevenueCat - 인앱 구매 관리

6. 이용자의 권리

이용자는 언제든지 앱 내 설정에서 계정을 삭제하고 모든 데이터를 제거할 수 있습니다. Google Calendar 연동은 사용자의 Google 계정 권한 설정 또는 앱 내 설정을 통해 해제할 수 있습니다.
